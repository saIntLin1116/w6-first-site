# W6 個人行程與任務管理系統

這是課程 W6 的前端練習，使用原生 HTML、CSS 與 JavaScript 製作的靜態單頁。頁面以繁體中文呈現今日行程和待辦事項，並支援在瀏覽器中新增、刪除與更新清單。

## 功能

- 顯示今天的日期。
- 顯示預設的三筆今日行程，並依時間排序。
- 透過表單新增行程，也可以刪除行程。
- 新增及刪除待辦事項。
- 點擊待辦事項左側的狀態按鈕，在「待處理」、「進行中」與「已完成」之間切換。
- 依目前清單內容更新行程和待辦數量。
- 支援手機窄螢幕版面。

## 使用方式

1. 下載或複製這個專案。
2. 用瀏覽器直接開啟 `index.html`。
3. 在「新增行程」區塊填入名稱和時間，按「加入今日行程」。
4. 在「今日待辦」區塊輸入事項、選擇狀態，再按「＋」新增。

## 專案檔案

- `index.html`：頁面結構與表單。
- `style.css`：頁面樣式與響應式版面。
- `script.js`：日期、清單新增／刪除、狀態切換及行程排序功能。

## 資料說明

這是純前端練習，沒有連接 API 或資料庫。新增、刪除和狀態變更只保存在目前開啟的頁面中；重新整理或關閉頁面後，會回到程式內的預設清單。
