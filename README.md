# Project A｜個人行程與任務管理系統

這個 Repo 延續 W6 的原生 HTML、CSS 與 JavaScript 前端，目前開始加入 Project A 的 Firebase Google 登入與 Firestore 個人資料保存。

## 功能

- 顯示今天的日期。
- 使用 Google 登入與登出。
- 登入後可在「清單／今日／行事曆」切換。
- 任務先新增到清單，再自行加入今日或移回清單。
- 今日任務可上移、下移，並突出目前先做的第一件事。
- 任務可編輯名稱、截止日期、預估分鐘、難度與備註；可完成、恢復待辦或刪除。
- 月曆可切換月份，點選日期查看該日的線性行程。
- 月曆每天按行程顯示最多三個類別色點；更多行程以「+N」表示。
- 行程可新增、編輯、刪除，支援日期、類別、全天或開始／結束時間及備註；類別可使用建議選項或自行輸入。
- 新增類別時可自選顏色；類別名稱與固定顏色保存在自己的帳號中，之後可重複使用。
- 行程時間可用鍵盤輸入，輸入 `0930` 會整理成 `09:30`；每日行程會顯示開始與結束時間，並檢查結束時間晚於開始時間。
- 登出或切換登入狀態時清除畫面上的舊帳號資料。
- 所有個人資料存於 `users/{Firebase UID}/tasks`、`events` 或 `categories`。
- 支援手機窄螢幕版面。

## 使用方式

1. 下載或複製這個專案。
2. 透過本機網站伺服器或正式 HTTPS 網址開啟（Firebase 模組不能以 `file://` 直接執行）。
3. 使用 Google 登入。
4. 在「新增行程」區塊填入名稱、日期及全天或時間；在「清單」輸入任務並新增。

## 專案檔案

- `index.html`：頁面結構與表單。
- `style.css`：頁面樣式與響應式版面。
- `script.js`：Google 登入、頁面切換、任務與行程操作，以及 Firestore 讀寫。
- `firestore.rules`：每個登入者只可讀寫自己 UID 下的資料；目前 Firebase 規則已發布，網站程式會在該 UID 下使用 `tasks`、`events` 和 `categories` 子集合。

## 資料說明

介面使用提供的色票：靛藍黑 `#16202b`、海洋藍 `#114665`、莓果酒紅 `#720f32`、柔霧紫紅 `#7b445a`、淡灰 `#d1d1d6`。Firebase Web 設定值是瀏覽器端公開設定，不能用它取代資料庫安全規則。Firestore 的 UID 隔離規則已發布，且曾以規則模擬器確認未登入讀取遭拒、相同 UID 可讀、不同 UID 遭拒；仍需再以實際第二個帳號做網站端驗收。瀏覽器端使用 Firebase CDN 模組，需要網路連線。
